# Virtual Systems and Services Lab

This project documents my practical work in virtual systems and services, including system setup, network configuration, and server connectivity testing.

## Project Overview:
In this lab, I worked on setting up virtual machines and establishing communication between a client and server environment. I also tested network connectivity between virtual and physical machines to ensure proper system integration.

Additionally, Python scripts were used on both the main machine and virtual machines to verify connectivity and system communication.

## Project Steps:
- Step 1: Virtual machine setup
- Step 2: Operating system installation
- Step 3: Network configuration (IP, DNS, AD setup)
- Step 4: Server setup and testing
- Step 5: Client-server connectivity testing
- Step 6: Python-based connectivity verification
